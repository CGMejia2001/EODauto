Install EODAuto Automation
Open the automation script so Tampermonkey can install it automatically.
  1. Open the EODAuto script on GitHub Gist: View Gist.
  2. After installing the Tampermonkey extension, open your browser's extensions list and click Tampermonkey.
  3. In Tampermonkey, click Dashboard. When redirected, click the + (create) icon to add a new userscript.
  4. Copy the contents of the Gist and paste it into the Tampermonkey editor, then choose File > Save.
  5. Return to Tampermonkey's Installed Userscripts list and ensure the EODAuto script is enabled.
  6. Once enabled, mark this step complete.
